  <action>
Create three POSIX-compatible shell wrappers under `src/templates/copilot/hooks/`.

`pre-tool-use.sh`:
- read stdin into `PAYLOAD`
- resolve `ROOT="$(git rev-parse --show-toplevel 2>/dev/null || pwd)"`
- call `.codewiki/hooks/pre-wiki-context.sh` if present
- default to allow/no-op behavior; do not deny tools by default
- exit 0 always

`post-tool-use.sh`:
- read stdin and resolve `ROOT`
- call `.codewiki/hooks/post-verify.sh`
- if output is non-empty, emit JSON containing an `additionalContext` field with escaped output
- emit `{}` when empty
- exit 0 always

`agent-stop.sh`:
- read stdin and resolve `ROOT`
- if the payload or environment indicates an already CodeWiki-triggered follow-up, emit `{"decision":"allow"}` or `{}` and exit 0
- call `.codewiki/hooks/session-end.sh`
- only when output is non-empty, emit `{"decision":"block","reason":"..."}` with escaped output
- emit `{"decision":"allow"}` or `{}` when there is no clear follow-up
- include comments stating `agentStop` is the meaningful post-turn hook and `sessionEnd` is cleanup-only
  </action>
  <acceptance_criteria>
    - Each wrapper starts with `#!/bin/sh`
    - `pre-tool-use.sh` contains `pre-wiki-context.sh`
    - `post-tool-use.sh` contains `post-verify.sh` and `additionalContext`
    - `agent-stop.sh` contains `session-end.sh`, `agentStop`, `sessionEnd`, `"decision":"block"`, and `"decision":"allow"`
    - Every wrapper contains `git rev-parse --show-toplevel`
  </acceptance_criteria>
